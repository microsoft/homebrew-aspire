# Support

## How to file issues and get help

This project uses [GitHub Issues in the `microsoft/aspire` repository](https://github.com/microsoft/aspire/issues)
to track bugs and feature requests for the Aspire CLI and its Homebrew cask. Please search the
existing issues before filing new issues to avoid duplicates. For new issues, file your bug or
feature request as a new Issue.

For help and questions about using this project, see the [Aspire documentation](https://aspire.dev/)
and the [Aspire discussions](https://github.com/microsoft/aspire/discussions).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
